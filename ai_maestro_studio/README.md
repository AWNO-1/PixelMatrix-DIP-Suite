## 🌟 نبذة عن المشروع (Project Abstract)
مشروع **AI Maestro Suite** هو منظومة رؤية حاسوبية متكاملة تعمل في الزمن الحقيقي (Real-Time CV System) عبر كاميرا ويب قياسية عادية بدون أي مجسات خارجية أو قفازات مكلفة. يقوم النظام باستخراج 33 نقطة مفصلية للهيكل العظمي و 21 نقطة لكل يد بالتوازي، وترجمة الحركات الحركية الحيوية (Biomechanical Motion) إلى إشارات تحكم موسيقية ستيريو لحظية لقيادة أوركسترا سيمفونية وعزف 5 آلات موسيقية بوليفونية كاملة.

## 🚀 التشغيل السريع للمنظومة (Quick Start)

### 1. المتطلبات البرمجية
* نظام التشغيل: Windows 10 / 11 (64-bit)
* لغة البرمجة: Python 3.10+
* كاميرا ويب عادية (Webcam 720p / 30 FPS)

### 2. تثبيت الحزم (Dependencies Installation)
```bash
pip install -r requirements.txt
```

### 3. إطلاق الاستوديو بخطوة واحدة
اضغط نقراً مزدوجاً على الملف:
```cmd
run_studio.bat
```
أو عبر سطر الأوامر:
```bash
python studio_launcher.py
```

## 🎛️ الأنماط والآلات المتاحة في الاستوديو (Modes & Instruments)

| # | النمط / الآلة | الملف المصدري | سكربت التشغيل المباشر | الوصف التقني |
|---|---|---|---|---|
| **1** | **مسرح المايسترو السينمائي** | `modes/maestro_hall.py` | `run_maestro_hall.bat` | قيادة أوركسترا حرة بالذكاء الاصطناعي (BiLSTM)، تحكم متري بالسرعة، كشافات حجمية، وتقييم بيوميتري للدرجات. |
| **2** | **تحدي لعبة الإيقاع** | `modes/rhythm_challenge.py` | `run_rhythm_game.bat` | لعبة تفاعلية بكرات إيماءات هابطة، نقاط دقة الإيقاع، وتفاعل أوركسترالي ديناميكي حي. |
| **3** | **البيانو الهوائي** | `modes/air_piano.py` | `run_air_piano.bat` | 24 مفتاحاً (أوكتافين)، 10 أصابع بوليفوني متزامن، استشعار سرعة الضغط رأسياً، و5 بنوك أصوات SoundFont. |
| **4** | **الدرامز والإيقاع الشرقي** | `modes/air_drums.py` | `run_air_drums.bat` | 7 منصات إيقاعية 3D في الفضاء الهوائي، محرك إجرائي PCM (دم/تك/رق/صاجات)، وعداد كومبو حماسي. |
| **5** | **العود الشرقي والجيتار** | `modes/air_strings.py` | `run_air_strings.bat` | دوزان عربي أصيل 5 أوتار مع محاكاة الريشة الافتراضية واهتزاز الأوتار وكوردات الجيتار الستة. |
| **6** | **الكمان الكلاسيكي** | `modes/air_violin.py` | `run_air_violin.bat` | محاكاة فيزياء احتكاك القوس باليد اليمنى، التوليف المستمر، والفيبراتو الطبيعي باليد اليسرى. |

## ⌨️ لوحة التحكم والاختصارات (Global Shortcuts)

* **داخل المشغل الرئيسي:**
  * `المؤشر الهولوجرافي`: تحكم بدون لمس عبر الكاميرا (ثبت اليد ثانية واحدة فوق البطاقة، أو المس السبابة بالإبهام Pinch).
  * `[1]` إلى `[6]`: تشغيل الآلة مباشرة عبر لوحة المفاتيح.
  * `[T]`: فتح نافذة فريق العمل والإشراف الأكاديمي الفاخرة.
  * `[C]`: تشغيل أو إيقاف خلفية الكاميرا الحية (Live Camera Feed).
  * `[Q]` أو `[ESC]`: إغلاق المشغل.
* **داخل الآلات الموسيقية ومسرح المايسترو:**
  * `[T]`: فتح نافذة فريق العمل والإشراف الأكاديمي.
  * `[B]`: تشغيل / إيقاف الإيقاع المصاحب (Backing Beat).
  * `[S]`: تبديل ستايل الإيقاع (موسيقا مقسوم شرقي، جاز، ديسكو، روك، تشيل سوينغ).
  * `[+] / [-]`: تسريع أو تبطيء سرعة الإيقاع (BPM).
  * `[E]`: إظهار لوحة التقييم البيوميتري الذكي ودرجة الأداء.
  * `[Q]`: الخروج من الآلة والعودة التلقائية للمشغل الرئيسي.
