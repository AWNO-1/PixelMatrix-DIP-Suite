## 1️⃣ مشروع PixelMatrix Studio (محرر الصور المتقدم)

### ✨ المميزات الرئيسية:
- **نواة معالجة أصيلة 100% (Client-Side 60 FPS):** كافة خوارزميات كاني، الوسيط، أوتسو، التقطيع البتي، ومصفوفات الالتفاف تم بناؤها ذاتياً من الصفر دون أي مكتبات جاهزة على المتصفح.
- **14 أداة تفاعلية متكاملة:**
  1. التحويلات الهندسية (Affine Transformations: تدوير، انعكاس، قص، تحجيم).
  2. العمليات النقطية (Point Operations: لوغاريتم، غاما، تمدد تبايني، تقطيع بتي، ومساواة الهيستوغرام).
  3. الفلاتر المكانية (Spatial Filtering: كاشف Canny الحقيقي، Sobel، Prewitt، Laplacian، Highboost).
  4. معمل الحسابات ومزج الصور (Arithmetic & Blending Lab: طرح، جمع، متوسط، ضرب أقنعة، ومزج موزون).
  5. معمل الترميم وإزالة الضوضاء (Restoration: فلتر الوسيط الحقيقي، Wiener، وحساب PSNR/MSE فوري).
  6. التجزئة وعزل الألوان (Segmentation: عنقدة K-Means، عزل كروما، وأقنعة لونية).
  7. العمليات المورفولوجية (Morphology: تآكل، تمدد، فتح، إغلاق، تدرج، وقبعة علوية).
  8. جداول التلوين الزائف (Pseudo-Color LUTs: حراري، جحيم، سيبيا، بارد، نيون).
  9. الإخفاء الرقمي للبيانات (LSB Steganography: إخفاء واستخراج رسائل مشفرة داخل البت الأقل أهمية).
  10. الذكاء الاصطناعي (AI Mask: عزل الخلفيات المعقدة).
  11. أداة الرسم والتعليق (Annotation & Drawing Studio).
  12. المعاينة ثلاثية الأبعاد (3D Perspective Studio).
  13. طيف التردد ومصفوفة البكسلات (2D FFT Spectrum & Pixel Matrix Inspector).
  14. الاستوديو البيومتري لجوازات السفر (ICAO Doc 9303 Compliance Check).
- **استوديو مطابقة وضعيات الجسم (PoseLook Integration):** ربط الكاميرا الحية بالذكاء الاصطناعي (BlazePose) لمطابقة وضعية المستخدم مع صورة مرجعية ثم التقاطها وإرسالها للمحرر.
- **دليل استخدام مدمج PDF (17 صفحة):** دليل شامل ومصور متاح للتحميل مباشرة من داخل التطبيق.

### 🚀 تشغيل PixelMatrix:

## 2️⃣ مشروع AI Maestro Studio (المايسترو والآلات الافتراضية)

### ✨ المميزات الرئيسية:
- **نظام رؤية حاسوبية تفاعلي في الزمن الحقيقي (Real-Time CV):** استخراج وتتبع 33 نقطة للهيكل العظمي (Body Pose) و 21 نقطة لكل يد عبر كاميرا ويب عادية.
- **قيادة الأوركسترا الموسيقية السيمفونية:** التحكم في تمبو الموسيقى والشدة الصوتية والتعبير الحركي بحركات يد المايسترو.
- **5 آلات موسيقية افتراضية تفاعلية بدون لمس:**
  1. **البيانو الهوائي (Air Grand Piano):** لوحة مفاتيح بيانو تفاعلية تعزف بلمس الهواء بالأصابع.
  2. **الطبول الهوائية (Air Drums):** محاكاة طقم درامز كامل بالحركة الحرة.
  3. **العود / الجيتار الهوائي (Air Strings / Oud):** عزف الأوتار بالنقر في الفضاء.
  4. **الكمان الهوائي (Air Violin):** محاكاة حركة القوس واليد الحساسة للنغمات.
  5. **لعبة الإيقاع التفاعلية (Rhythm Conductor Game):** تدريب وتقييم التوافق العصبي الحركي مع الإيقاع.
- **توليف صوتي حقيقي (MIDI Synthesis):** عبر محرك `FluidSynth` عالي النقاء وبنك أصوات `orchestra.sf2`.

### 🚀 تشغيل AI Maestro Studio:
1. تثبيت المتطلبات (لأول مرة):
```bash
cd ai_maestro_studio
pip install -r requirements.txt
```
2. إطلاق المنظومة:
اضغط نقراً مزدوجاً على:
```cmd
ai_maestro_studio/run_studio.bat
```
