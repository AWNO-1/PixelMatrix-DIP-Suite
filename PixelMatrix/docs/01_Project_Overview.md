## 2. ملخص المشروع (Executive Summary)

مشروع **PixelMatrix** هو منصة استوديو رقمية متكاملة عالية الأداء مخصصة لتطبيق واختبار وعرض خوارزميات **معالجة الصور الرقمية (Digital Image Processing)** والرؤية الحاسوبية. 

تم تصميم المنصة كبيئة هجينة فريدة تجمع بين:
1. **محرك تنفيذ فوري على المتصفح (Client-Side Canvas 60 FPS):** ينفذ كافة خوارزميات تحسين البكسل، والالتفاف المكاني، والفرز الإحصائي، والعمليات الحسابية، وحسابات الـ Histogram والـ PSNR بدون أي تأخير زمني (0ms latency)، وبدون الحاجة لاتصال بالإنترنت.
2. **محرك معالجة خلفي متقدم (FastAPI + OpenCV + NumPy):** لمعالجة المهام الثقيلة ونماذج الذكاء الاصطناعي لعزل الخلفية (U-2-Net)، والتعامل مع مصفوفات التردد المعقدة وعمليات الـ GrabCut.

## 3. الأهداف الأكاديمية والهندسية (Project Goals)

1. **التطبيق الصارم للمفاهيم الرياضية:** الانتقال من المعادلات النظرية في المراجع الكلاسيكية (مثل كتاب *Digital Image Processing* لمؤلفيه Rafael C. Gonzalez & Richard E. Woods) إلى كود برمجي تنفيذي دقيق يتعامل مباشرة مع مصفوفات البكسلات ثنائية وثلاثية الأبعاد $f(x, y)$.
2. **الاستغناء التام عن المحاكاة السطحية:** التأكيد على أن كافة الخوارزميات (مثل كاشف كاني، وفلتر الوسيط، وتجزئة K-Means، وتشفير LSB) هي خوارزميات حقيقية بالكامل تعمل على بيانات البكسلات الخام ($Uint8ClampedArray$).
3. **الربط بين النظرية والتطبيق الصناعي:** توفير مختبر للعمليات الحسابية ومزج الصور لمحاكاة كشف التغيرات (Change Detection) وإزالة الضوضاء (Averaging)، بالإضافة إلى وحدة بيومترية تفحص مطابقة صور الجوازات والهوية لمعايير منظمة الطيران المدني الدولي (ICAO Doc 9303).
4. **التميز البصري في تجربة المستخدم (UI/UX Excellence):** تصميم واجهة استوديو مستقبلية بطابع زجاجي نيون أزرق كهربائي (Deep Obsidian & Electric Cyan Glassmorphism) تركز على جعل الكانفاس بطلاً للواجهة مع توفير شاشات بيانات آنية (Live HUD) ومقارنة تفاعلية بالستارة وعدسة فحص بكسلية $5\times5$.

## 4. الميزات الرئيسية للمنصة (Core Features)

| الوحدة البرمجية | الوظيفة الأكاديمية | النطاق الرياضي |
| :--- | :--- | :--- |
| **تحسينات البكسل (Point Ops)** | تحويل لوغاريتمي، تصحيح غاما، تقطيع المستويات البتية، تمدد التباين | النطاق النقطي $s = T(r)$ |
| **الفلاتر المكانية (Spatial Filtering)** | كاشف كاني الحقيقي، سوبيل، بريويت، غاوسي، وزيادة الحدة Highboost | الالتفاف المكاني $g(x,y) = f(x,y) * h(x,y)$ |
| **معمل الحسابات والمزج (Arithmetic Lab)** | طرح $\|A-B\|$، جمع $(A+B)/2$، ضرب $A \cdot B/255$، قسمة $A/(B+1)$، ومزج $\alpha$ | الجبر البكسلي Matrix Operations |
| **الترميم وقياس الجودة (Restoration & PSNR)** | فلتر الوسيط الحقيقي (Median Sorting)، مرشح وينر، وحساب PSNR و MSE | الإحصاء المرتب ونماذج تدهور الإشارة |
| **التجزئة وعزل الألوان (Segmentation)** | تجزئة K-Means العنقودية، عزل لوني Color Masking، وأقنعة ثنائية | التجميع الإحصائي وتقسيم فضاء الألوان |
| **المعالجة المورفولوجية (Morphology)** | التآكل، التمدد، الفتح، الإغلاق، قبعة الرأس، والتدرج المورفولوجي | نظرية المجموعات وعناصر البنية SE |
| **الرؤية الحرارية والطيفية (Thermal LUTs)** | جداول تلوين FLIR Ironbow، و Jet، و Night Vision، و X-Ray | تعيين الألوان الزائفة False Coloring |
| **إخفاء وتشفير البيانات (Steganography)** | حقن واستخراج نصوص سرية عبر البت الأقل أهمية LSB | تعديل المستوى البتي الصفري |
| **الفحص البيومتري (3 Poses Biometrics)** | قياس زوايا استقامة الرأس وتوازي الكتفين لصور الجواز والفيزا والهوية | التحليل الهندسي واستخراج المعالم |

## 5. البيئة التقنية وحزم التطوير (Technology Stack)

- **الواجهة الأمامية (Frontend):**
  - **React 18** مع معمارية المكونات التفاعلية وحلقات الخطاف (Hooks).
  - **Vite 6** لبناء وتجميع الحزم بسرعة فائقة وتحديث حي فوري (HMR).
  - **Tailwind CSS 3** مع تخصيصات Glassmorphism وألوان Deep Obsidian و Electric Cyan.
  - **HTML5 Canvas API** للتعامل المباشر مع الذاكرة البكسلية $ImageData$.
  - **Lucide Icons** للأيقونات الهندسية الدقيقة.
- **الخادم الخلفي (Backend):**
  - **Python 3.10+**
  - **FastAPI** لبناء واجهات برمجية غير متزامنة فائقة السرعة (Asynchronous REST API).
  - **OpenCV 4.10 (cv2)** لمعالجة الصور الصناعية ومصفوفات الرؤية الحاسوبية.
  - **NumPy 2.0** للعمليات المصفوفية المتجهة السريعة.
  - **Uvicorn** كخادم ASGI قياسي.
